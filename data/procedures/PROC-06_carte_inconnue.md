# PROC-06 — Carte ou transaction introuvable

> Document fictif rédigé pour un projet pédagogique.

Si l'identifiant de carte ou de transaction fourni n'existe pas dans le système :
1. ne formuler **aucune** hypothèse sur le client ni sur la transaction ;
2. ne proposer **aucune** action (pas de blocage) ;
3. demander à l'émetteur de l'alerte de vérifier l'identifiant (format attendu : CARD-00000 pour une carte, un nombre à 6 chiffres pour une transaction) ;
4. si l'identifiant est confirmé mais toujours introuvable, signaler l'incident à l'équipe Données.
