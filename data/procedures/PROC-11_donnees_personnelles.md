# PROC-11 — Protection des données personnelles

> Document fictif rédigé pour un projet pédagogique.

- Ne communiquer les informations d'un client qu'aux personnes habilitées et dans le cadre d'une investigation.
- Ne jamais afficher ni demander un numéro de carte complet, un code PIN ou un mot de passe.
- Limiter les informations affichées au strict nécessaire de l'enquête (minimisation).
- Toute demande sans rapport avec une investigation de fraude doit être refusée.
